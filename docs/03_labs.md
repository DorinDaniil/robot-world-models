# Лабораторный практикум

Каждая лабораторная завершается запускаемым артефактом и отчётом по форме из
`docs/00_syllabus.md`. Лекции, на которые опирается работа, указаны в скобках.

## Лаб. 0. Окружение

- Установка по README; `pytest` проходит; `scripts/00_view_arm.py` открывает окно симулятора.
- Контрольный вопрос: почему шаг управления отличается от шага физики и как `frame_skip`
  связан с частотой управления (L2, §2.3).

## Лаб. 1. Модель робота и среда (L2, `docs/06_arm_geometry.md`)

В репозитории даны: модель `arm5` (5 DoF + захват), её кинематика в формулировке
произведения экспонент (`rwm.kinematics`), среда `PickEnv` и аналитический контроллер
захвата (`rwm.control`). Задания:

1. Вывести замкнутую форму прямой кинематики `arm5` из произведения экспонент (06, упр. 1)
   и выписать $J_p$ в замкнутой форме, найти особые конфигурации (06, упр. 2).
2. Исследовать отклик позиционного актуатора на ступенчатое воздействие при разных $k_v$
   и сравнить с оценкой $\zeta$ из 06, §7 (L2, упр. 2).
3. Построить рабочую зону захвата сверху методом Монте-Карло (06, упр. 4).
4. Найти минимальные трение и жёсткость захвата, при которых контроллер ещё поднимает
   кубик (06, упр. 5); объяснить результат через баланс сил.
5. Реализовать `PushEnv` (довести кубик в целевую зону, не поднимая) по образцу `PickEnv`,
   с тестами по образцу `tests/test_pick_env.py`, включая аналитический контроллер как
   верхнюю оценку.

Артефакт: отчёт с выводами и графиками, `src/rwm/envs/push.py` с тестами.

## Лаб. 2. Базовая линия: SAC (L1)

1. Реализовать SAC по алгоритму 1.1 в `src/rwm/algos/sac.py`.
2. Обучить на `ReachEnv` (`state`), 3 сида. Ожидаемый результат: доля успехов $> 0.9$ при
   $10^5$ шагов среды.
3. Сверить с реализацией CleanRL при тех же гиперпараметрах; расхождение кривых должно
   лежать в пределах разброса по сидам.
4. Абляции: без второго $Q$; с фиксированным $\alpha$; усечение как завершение (L1, упр. 4).

Артефакт: `scripts/10_train_sac.py`, `configs/sac_reach.yaml`, кривые по 3 сидам, чекпоинт.

## Лаб. 3. TD-MPC2 (L4)

Поэтапно, каждый этап — отдельный эксперимент:

1. MPPI с истинной динамикой симулятора как моделью (L4, упр. 2): доля успехов при
   $H \in \{1, 3, 5, 10\}$. Это изолирует планировщик от модели.
2. Энкодер, динамика, голова награды на буфере, собранном SAC: ошибка предсказания
   награды и латента на горизонте 1, 5, 10.
3. Ансамбль $Q$ с TD-лоссом и two-hot регрессией.
4. MPPI в латенте с обученной моделью, без policy prior.
5. Policy prior, SimNorm, остальные элементы §4.3; сверка с эталонной реализацией.

Артефакт: `src/rwm/algos/tdmpc2.py`, `scripts/20_train_tdmpc2.py`, сравнение с SAC по
числу шагов среды до доли успехов 0.9.

## Лаб. 4. RSSM и обучение в воображении (L3)

1. Энкодер/декодер для $64 \times 64$, RSSM с категориальным латентом, KL с free bits.
   Диагностика открытого цикла (L3, §3.6) до обучения политики.
2. Головы награды и продолжения.
3. Актёр-критик в воображении с $\lambda$-доходностью (L3, упр. 5).
4. Нормировки DreamerV3 (symlog, перцентильная нормировка доходности).
5. Обучение на `ReachEnv(obs_mode="pixels")`, затем `PushEnv`. Выполняется на сервере.

Артефакт: `src/rwm/algos/dreamer.py`, `scripts/30_train_dreamer.py`, видео «наблюдение /
предсказание», кривые по 3 сидам.

## Лаб. 5. Модель реальной руки и рандомизация домена (L5)

1. Подключить `trs_so_arm100` (SO-101) из `mujoco_menagerie`; задачи reach → push →
   pick-and-place.
2. Рандомизация масс, трения, задержки действий, параметров камеры; обёртка задержки
   (L5, упр. 4).
3. Параллельные среды; на сервере — MJX при необходимости.
4. Сравнение SAC / TD-MPC2 / Dreamer на одной задаче, 3 сида, единый протокол оценки.

Артефакт: таблица результатов, видео политик, отчёт о влиянии рандомизации.

## Лаб. 6. Физическая рука и обучение по демонстрациям (L5)

1. Сборка SO-101 (ведущая и ведомая), калибровка в LeRobot.
2. Запись $\ge 50$ демонстраций задачи; обучение ACT и Diffusion Policy; оценка на
   устройстве по протоколу §5.6.
3. Перенос политики из лаб. 5 на задачу reach; измерение разрыва.
4. Исследовательская часть: латентная модель, обученная на записях телеоперации, как среда
   для дообучения политики; сравнение с результатом без дообучения.

Артефакт: датасет, видео, итоговый отчёт.
