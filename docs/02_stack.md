# Программный стек и вычислительные ресурсы

## Критерии выбора

1. Работа на Windows 10 (разработка) и Linux (сервер) из одного кода.
2. Исходный код всех компонентов доступен и обозрим: алгоритмы реализуются в курсе с нуля,
   внешние библиотеки используются как эталон для сверки.
3. Наличие пути к физическому манипулятору с той же моделью в симуляции.

## Физические симуляторы

| Симулятор | Платформа | Параллелизм | Модели манипуляторов | Решение |
|---|---|---|---|---|
| MuJoCo 3 | Windows/Linux/macOS, CPU | процессы (десятки сред) | `mujoco_menagerie`: Franka, UR5e, xArm, SO-ARM100 | основной |
| MuJoCo MJX | JAX, GPU | тысячи сред | те же модели | для масштабирования на сервере (Linux) |
| gymnasium-robotics | поверх MuJoCo | — | Fetch, Shadow Hand | эталонные задачи для сверки |
| robosuite | поверх MuJoCo | — | Panda, Sawyer, UR5e; OSC-контроллеры | при переходе к управлению положением конца |
| ManiSkill3 (SAPIEN) | Linux, GPU | тысячи сред, рендер на GPU | обширный набор задач манипуляции | пиксельные эксперименты на сервере |
| Isaac Lab | Windows/Linux, NVIDIA | тысячи сред | Franka и др. | не используется: высокие требования к ресурсам |
| PyBullet | любая | слабый | устаревшие бенчмарки | не используется |

Основание выбора MuJoCo: точная и гладкая модель контактов (лекция 2, §2.2), открытый код,
малые накладные расходы, единый формат моделей с реальными руками.

## Вычислительные ресурсы

| Машина | Назначение |
|---|---|
| Рабочая станция: RTX 5060 (8 ГБ), Windows 10 | разработка, тесты, эксперименты на векторе состояния (лаб. 0–3), визуализация |
| Сервер: RTX 5090 (32 ГБ) | пиксельные модели мира (лаб. 4), прогоны по нескольким сидам, параллельные среды (MJX/ManiSkill), дообучение политик по демонстрациям |

Правило: один и тот же скрипт запускается на обеих машинах; различается только конфиг
(`configs/*_debug.yaml` для рабочей станции). Оценка памяти: DreamerV3 размера XL (200M
параметров) и SmolVLA в режиме дообучения укладываются в 32 ГБ при батче 16–32.

PyTorch для архитектуры Blackwell (sm_120) требует сборки с CUDA 12.8:

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
```

## Физический манипулятор

SO-101 (TheRobotStudio; поддержан LeRobot): 5 степеней свободы и захват, сервоприводы
Feetech STS3215, 3D-печатные звенья, стоимость комплектующих порядка 150–250 USD. Модель
`trs_so_arm100` в `mujoco_menagerie`. Используется в лаб. 5–6.

## Принятые соглашения

- Физика: MuJoCo 3.x; учебная рука `assets/arm3.xml`, далее модели из `mujoco_menagerie`.
- API среды: Gymnasium 1.x.
- Обучение: PyTorch; конфиги YAML; логи TensorBoard.
- Качество кода: ruff, pytest (`docs/05_code_conventions.md`).
