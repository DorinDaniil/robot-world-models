# Соглашения по коду

Цель: код должен читаться как приложение к лекции. Критерий — студент с пререквизитами курса
понимает любой файл за один проход, не открывая другие.

## Структура

- `src/rwm/envs` — среды. Общая механика (физика, рендер) в `base.MujocoEnv`; каждая задача —
  один файл с тремя методами-хуками (`_get_obs`, `_reset_task`, `_task_step`) и `_apply_action`.
- `src/rwm/models` — нейросетевые модули без обучающего цикла: энкодеры, динамика, головы.
  Модуль не знает о среде и буфере.
- `src/rwm/algos` — один алгоритм = один файл с классом `Agent` (методы `act`, `update`,
  `state_dict`) и функцией `train(cfg)`.
- `scripts` — тонкие точки входа: разбор аргументов, загрузка конфига, вызов `train`.
  Нумерация `NN_` по лабораторным.
- `configs` — все гиперпараметры. В коде нет констант, влияющих на результат эксперимента.
- `tests` — поведение, а не реализация: тесты обращаются только к публичному API.

## Правила

1. **Математика в докстринге.** Каждый лосс и каждое обновление сопровождаются формулой в
   том же обозначении, что в лекции, и ссылкой на статью/лекцию.
2. **Одна ответственность.** Функция делает одно действие; если нужен комментарий «// часть 2»,
   это две функции.
3. **Без преждевременных абстракций.** Базовый класс или интерфейс появляется, когда есть второй
   конкретный случай, а не «на будущее».
4. **Явные формы тензоров.** Комментарий `# (B, T, D)` на каждом нетривиальном тензоре.
5. **Детерминизм.** Любая случайность идёт через `np_random`/`torch.Generator`, посеянные из
   конфига. Тест `test_determinism` обязателен для сред.
6. **Числовая устойчивость.** `log` только от величин с нижней границей; `clip` градиентов
   в конфиге; `symlog` для величин с тяжёлыми хвостами.
7. **Производительность без магии.** Векторизация по батчу, отсутствие циклов по времени там,
   где возможен `cumsum`/скан; профилирование перед оптимизацией.
8. **Типы и стиль.** Аннотации типов на публичных функциях; `ruff check` и `ruff format` без
   замечаний; строка ≤ 100 символов; язык идентификаторов — английский, язык докстрингов —
   русский.
