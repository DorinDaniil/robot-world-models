# Лекция 3. Model-based RL и латентные модели динамики

Цель: обосновать, зачем учить модель среды, вывести обучающую цель латентной модели
(вариационная нижняя оценка), описать RSSM и обучение политики в воображении (семейство Dreamer).

## 3.1. Зачем модель

Model-free методы оценивают $Q^\pi$ только по реальным переходам; каждый градиентный шаг
требует новых данных или повторного использования старых. Модель $\hat P(s' \mid s, a)$,
$\hat r(s,a)$ позволяет (1) генерировать синтетические переходы (Dyna, Sutton 1990),
(2) планировать явно, (3) переносить знания между задачами с общей динамикой. Цена —
ошибка модели, которая накапливается с горизонтом.

**Утверждение 3.1 (лемма о симуляции).** Пусть $\hat{\mathcal M}$ отличается от
$\mathcal M$ только ядром переходов, и $\max_{s,a} \|\hat P(\cdot \mid s,a) - P(\cdot \mid s,a)\|_1
\le \varepsilon$. Тогда для любой политики $\pi$
$$\big|J_{\hat{\mathcal M}}(\pi) - J_{\mathcal M}(\pi)\big| \le
\frac{\gamma\, \varepsilon\, R_{\max}}{(1-\gamma)^2}.$$

*Набросок доказательства.* Разность значений раскладывается телескопически по шагам; на шаге
$t$ вклад ограничен $\gamma^t \cdot \varepsilon \cdot \|V\|_\infty \le \gamma^t \varepsilon
R_{\max}/(1-\gamma)$; суммирование по $t \ge 1$ даёт множитель $\gamma/(1-\gamma)$. $\square$

Зависимость $(1-\gamma)^{-2}$ показывает, что длинные прогоны по модели ненадёжны. Отсюда два
практических следствия: **короткие прогоны** от реальных состояний (MBPO, Janner et al., 2019:
горизонт $k = 1$–$5$ от состояний из буфера) и **оценка неопределённости** модели (ансамбли)
с штрафом за неё.

## 3.2. Латентные модели: зачем латент

Для наблюдений-изображений модель $p(o_{t+1} \mid o_t, a_t)$ в пространстве пикселей (а) дорога,
(б) тратит ёмкость на нерелевантные детали, (в) не даёт компактного состояния для политики.
Вместо этого вводится латентное состояние $z_t$ и генеративная модель

$$p(o_{1:T}, r_{1:T}, z_{1:T} \mid a_{1:T}) = \prod_{t=1}^{T}
\underbrace{p(z_t \mid z_{t-1}, a_{t-1})}_{\text{динамика}}\;
\underbrace{p(o_t \mid z_t)}_{\text{декодер}}\;
\underbrace{p(r_t \mid z_t)}_{\text{награда}}.$$

Точный апостериор $p(z_{1:T} \mid o_{1:T}, a_{1:T})$ невычислим; вводится вариационное
приближение, факторизованное по времени: $q(z_{1:T} \mid o_{1:T}, a_{1:T}) = \prod_t
q(z_t \mid z_{t-1}, a_{t-1}, o_t)$.

**Утверждение 3.2 (ELBO для последовательности).**
$$\log p(o_{1:T}, r_{1:T} \mid a_{1:T}) \;\ge\; \sum_{t=1}^T \mathbb{E}_{q}\Big[
\log p(o_t \mid z_t) + \log p(r_t \mid z_t)\Big]
- \sum_{t=1}^T \mathbb{E}_{q(z_{t-1})}\Big[\mathrm{KL}\big(q(z_t \mid z_{t-1}, a_{t-1}, o_t)
\,\|\, p(z_t \mid z_{t-1}, a_{t-1})\big)\Big].$$

*Вывод.* Неравенство Йенсена для $\log \mathbb{E}_q[p(o,r,z \mid a)/q(z \mid o,a)]$; факторизация
$p$ и $q$ по времени превращает логарифм произведения в сумму, и члены с $p(z_t \mid \cdot)$
и $q(z_t \mid \cdot)$ группируются в KL. $\square$

Интерпретация: реконструкция и предсказание награды заставляют $z_t$ содержать информацию
о наблюдении; KL-член заставляет динамику (prior) предсказывать то, что энкодер (posterior)
извлекает из следующего наблюдения. Именно KL делает модель пригодной для прогнозов без
наблюдений.

## 3.3. RSSM

Recurrent State-Space Model (Hafner et al., 2019) расщепляет состояние на детерминированную
и стохастическую части:
$$h_t = f_\theta(h_{t-1}, z_{t-1}, a_{t-1}) \quad\text{(GRU)}, \qquad
\text{prior } p_\theta(z_t \mid h_t), \qquad \text{posterior } q_\theta(z_t \mid h_t, e_\theta(o_t)).$$
Детерминированный путь $h_t$ переносит информацию на много шагов без накопления шума от
семплирования; стохастический $z_t$ моделирует многомодальность.

**Дискретные латенты (DreamerV2/V3).** $z_t$ — $K$ категориальных переменных по $K$ классов
($K = 32$), семплирование со straight-through оценкой градиента:
$z = \mathrm{onehot}(\text{sample}) + \text{probs} - \mathrm{sg}(\text{probs})$.
Эмпирически устойчивее гауссовых латентов для сложных наблюдений.

**Регуляризация KL (DreamerV3).** KL разделяется на два члена с остановкой градиента:
$$\mathcal{L}_{\text{KL}} = \beta_{\text{dyn}}\, \max\big(1, \mathrm{KL}(\mathrm{sg}(q) \| p)\big)
+ \beta_{\text{rep}}\, \max\big(1, \mathrm{KL}(q \| \mathrm{sg}(p))\big),
\quad \beta_{\text{dyn}} = 0.5,\ \beta_{\text{rep}} = 0.1.$$
Первый обучает prior подтягиваться к posterior, второй — posterior не уходить от prior
слишком далеко; порог 1 нат (free bits) отключает регуляризацию, когда она уже мала, не давая
латенту коллапсировать в prior.

**Полный лосс модели** на батче последовательностей $(B, T)$:
$$\mathcal{L}_{\text{wm}} = \mathbb{E}\Big[\sum_t -\log p(o_t \mid z_t, h_t) - \log p(r_t \mid z_t, h_t)
- \log p(c_t \mid z_t, h_t) + \mathcal{L}_{\text{KL},t}\Big],$$
где $c_t = 1 - d_t$ — предсказание продолжения эпизода (нужно для корректного бутстрапа в
воображении). Награда и ценности регрессируются в symlog-пространстве,
$\mathrm{symlog}(x) = \mathrm{sign}(x)\log(1 + |x|)$, что выравнивает масштабы задач.

## 3.4. Обучение политики в воображении

От каждого апостериорного состояния батча $(h_t, z_t)$ запускается прогон по prior на
горизонт $H = 15$ с действиями актёра $\hat a_\tau \sim \pi_\psi(\cdot \mid \hat s_\tau)$,
$\hat s_\tau = (\hat h_\tau, \hat z_\tau)$. Модель даёт $\hat r_\tau, \hat c_\tau$.

**λ-доходность** (обобщённое TD(λ) с бутстрапом критиком $v_\xi$):
$$R^\lambda_\tau = \hat r_\tau + \gamma \hat c_\tau \Big[(1-\lambda)\, v_\xi(\hat s_{\tau+1})
+ \lambda R^\lambda_{\tau+1}\Big], \qquad R^\lambda_{H} = v_\xi(\hat s_H),$$
$\lambda = 0.95$. Вычисляется обратной рекурсией по $\tau$ за $O(H)$.

**Критик**: регрессия $v_\xi(\hat s_\tau) \to \mathrm{sg}(R^\lambda_\tau)$ (в V3 — дискретная
регрессия на two-hot кодировку symlog-значения).

**Актёр**: максимизация $R^\lambda$. Поскольку динамика дифференцируема, в Dreamer V1/V2 для
непрерывных действий градиент берётся напрямую через прогон (reparameterization). V3 использует
REINFORCE с нормированным преимуществом и энтропийным бонусом:
$$\mathcal{L}_\pi = -\mathbb{E}\Big[\sum_\tau \mathrm{sg}\Big(\frac{R^\lambda_\tau - v_\xi(\hat s_\tau)}
{\max(1, S)}\Big) \log \pi_\psi(\hat a_\tau \mid \hat s_\tau) + \eta\, \mathcal{H}(\pi_\psi(\cdot \mid \hat s_\tau))\Big],$$
где $S$ — скользящая оценка разброса доходностей (разность 95-го и 5-го перцентилей). Нормировка
на $\max(1, S)$, а не на $S$, не усиливает шум при малых доходностях.

**Утверждение 3.3.** В воображении горизонт $H$ ограничивает накопление ошибки модели в
смысле утверждения 3.1 (с заменой $1/(1-\gamma)$ на $\sim H$), а бутстрап критиком заменяет
хвост доходности за горизонтом. Это обосновывает малые $H$ при больших $\gamma$.

## 3.5. Модели без декодера

Реконструкция наблюдения заставляет латент хранить всё, включая фон и шум. Альтернативы:
- **самосогласованность латента** (TD-MPC, лекция 4): $\|d(z_t, a_t) - \mathrm{sg}(e(o_{t+1}))\|^2$;
  латент обязан быть предсказуемым и информативным для награды и $Q$, но не для пикселей;
- **контрастные цели** и предобученные визуальные энкодеры (DINO-WM, Zhou et al., 2024):
  динамика учится в замороженном пространстве признаков.

Отсутствие декодера требует предосторожностей против коллапса (все $z$ одинаковы): в TD-MPC2 —
нормализация SimNorm и сигнал от $Q$/награды; в JEPA-подобных моделях — регуляризация дисперсии
или EMA-целевой энкодер.

## 3.6. Диагностика модели мира

Прежде чем учить политику, модель проверяют в открытом цикле: по $k$ первым наблюдениям
вычисляют posterior, затем $K$ шагов идут по prior с реальными действиями. Метрики:
ошибка предсказания награды $|\hat r - r|$, расстояние в латенте, для пикселей — визуальное
сравнение. Рост ошибки должен быть плавным; скачок на шаге $k+1$ означает, что prior не
согласован с posterior (слишком малый $\beta_{\text{dyn}}$ или KL ниже порога free bits
при неинформативном латенте).
