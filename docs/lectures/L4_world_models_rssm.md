# Лекция 4. Модели мира: ELBO для последовательностей, RSSM, обучение в воображении

Цель: обосновать, зачем учить модель среды, вывести обучающую цель латентной модели
(вариационная нижняя оценка), описать RSSM и обучение политики в воображении (семейство
Dreamer). Реализация: `src/rwm/algos/dreamer.py`.

## 4.1. Зачем модель

Model-free методы оценивают $Q^\pi$ только по реальным переходам. Модель
$\hat P(s' \mid s, a)$, $\hat r(s,a)$ позволяет (1) генерировать синтетические переходы
(Dyna, Sutton, 1990), (2) планировать явно (лекция 5), (3) переносить знания между задачами
с общей динамикой. Цена — ошибка модели, накапливающаяся с горизонтом.

**Утверждение 4.1 (лемма о симуляции).** Пусть $\hat{\mathcal{M}}$ отличается от
$\mathcal{M}$ только ядром переходов, причём
$\max_{s,a} \lVert \hat P(\cdot \mid s,a) - P(\cdot \mid s,a) \rVert_1 \le \varepsilon$.
Тогда для любой политики $\pi$

```math
\big\lVert V^\pi_{\hat{\mathcal{M}}} - V^\pi_{\mathcal{M}} \big\rVert_\infty \le
\frac{\gamma\, \varepsilon\, R_{\max}}{(1-\gamma)^2}.
```

*Доказательство.* Обозначим $V = V^\pi_{\mathcal{M}}$, $\hat V = V^\pi_{\hat{\mathcal{M}}}$,
$\Delta = \lVert \hat V - V \rVert_\infty$. Из уравнения Беллмана для обеих моделей

```math
\hat V(s) - V(s) = \gamma \sum_a \pi(a \mid s) \Big[
\sum_{s'} \big(\hat P - P\big)(s' \mid s, a)\, \hat V(s')
+ \sum_{s'} P(s' \mid s, a)\big(\hat V(s') - V(s')\big)\Big].
```

Первая сумма по модулю не превосходит $\varepsilon \lVert \hat V \rVert_\infty$, то есть
$\varepsilon R_{\max}/(1-\gamma)$; вторая — $\Delta$. Отсюда
$\Delta \le \gamma \varepsilon R_{\max}/(1-\gamma) + \gamma \Delta$, что даёт утверждение. $\square$

Зависимость $(1-\gamma)^{-2}$ показывает, что длинные прогоны по модели ненадёжны. Два
практических следствия: **короткие прогоны** от реальных состояний (MBPO, Janner et al.,
2019: горизонт $1$–$5$ от состояний из буфера) и **оценка неопределённости** модели
(ансамбли) со штрафом за неё.

## 4.2. Латентные модели

Для наблюдений-изображений модель $p(o_{t+1} \mid o_t, a_t)$ в пространстве пикселей
(а) дорога, (б) тратит ёмкость на нерелевантные детали, (в) не даёт компактного состояния
для политики. Вводится латентное состояние $z_t$ и генеративная модель последовательности

```math
p(o_{1:T}, r_{1:T}, z_{1:T} \mid a_{0:T-1}) = \prod_{t=1}^{T}
\underbrace{p(z_t \mid z_{t-1}, a_{t-1})}_{\text{динамика}}\;
\underbrace{p(o_t \mid z_t)}_{\text{декодер}}\;
\underbrace{p(r_t \mid z_t)}_{\text{награда}} .
```

**Соглашение об индексах.** Здесь $r_t$ — награда, полученная *при входе* в состояние $t$
(за переход $t-1 \to t$); в контракте Gymnasium та же величина возвращается как награда
шага $t-1$. Это соглашение DreamerV3; в коде голова награды читается со сдвигом на один шаг.

Точный апостериор $p(z_{1:T} \mid o_{1:T}, a)$ невычислим; вводится вариационное
приближение, факторизованное по времени:
$q(z_{1:T} \mid o_{1:T}, a) = \prod_t q(z_t \mid z_{t-1}, a_{t-1}, o_t)$.

**Утверждение 4.2 (ELBO для последовательности).**

```math
\log p(o_{1:T}, r_{1:T} \mid a) \;\ge\; \sum_{t=1}^T \mathbb{E}_{q}\Big[
\log p(o_t \mid z_t) + \log p(r_t \mid z_t)\Big]
- \sum_{t=1}^T \mathbb{E}_{q(z_{t-1})}\Big[\mathrm{KL}\big(q(z_t \mid z_{t-1}, a_{t-1}, o_t)
\,\big\Vert\, p(z_t \mid z_{t-1}, a_{t-1})\big)\Big].
```

*Вывод.* По неравенству Йенсена

```math
\log p(o, r \mid a) = \log \mathbb{E}_{q}\big[p(o, r, z \mid a)/q(z \mid o, a)\big]
\ge \mathbb{E}_q\big[\log p(o, r, z \mid a) - \log q(z \mid o, a)\big];
```

факторизация $p$ и $q$ по времени превращает логарифмы произведений в суммы, и члены
$\log p(z_t \mid \cdot) - \log q(z_t \mid \cdot)$ при усреднении по $q(z_t \mid \cdot)$
группируются в $-\mathrm{KL}$. $\square$

Интерпретация: реконструкция и предсказание награды заставляют $z_t$ содержать информацию
о наблюдении; KL-член заставляет динамику (prior) предсказывать то, что энкодер (posterior)
извлекает из следующего наблюдения. Именно KL делает модель пригодной для прогнозов без
наблюдений.

## 4.3. RSSM

Recurrent State-Space Model (Hafner et al., 2019) расщепляет состояние на детерминированную
и стохастическую части:

```math
h_t = f_\theta(h_{t-1}, z_{t-1}, a_{t-1}) \ \text{(GRU)}, \qquad
\text{prior } p_\theta(z_t \mid h_t), \qquad \text{posterior } q_\theta(z_t \mid h_t, e_\theta(o_t)).
```

Детерминированный путь $h_t$ переносит информацию на много шагов без накопления шума от
семплирования; стохастический $z_t$ моделирует многомодальность. Признак для всех голов —
$(h_t, z_t)$.

**Дискретные латенты (DreamerV2/V3).** $z_t$ — $K$ категориальных переменных по $K$ классов
($K = 32$), семплирование со straight-through оценкой градиента:
$z = \mathrm{onehot}(\text{sample}) + \text{probs} - \mathrm{sg}(\text{probs})$. Вперёд идёт
one-hot, назад — градиент через вероятности. К вероятностям примешивается $1\%$ равномерного
распределения (unimix): это удерживает KL конечным и не даёт категориям «умирать».

**Регуляризация KL (DreamerV3).** KL разделяется на два члена с остановкой градиента:

```math
\mathcal{L}_{\mathrm{KL}} = \beta_{\mathrm{dyn}}\, \max\big(1, \mathrm{KL}(\mathrm{sg}(q) \,\Vert\, p)\big)
+ \beta_{\mathrm{rep}}\, \max\big(1, \mathrm{KL}(q \,\Vert\, \mathrm{sg}(p))\big),
\quad \beta_{\mathrm{dyn}} = 0.5,\ \beta_{\mathrm{rep}} = 0.1 .
```

Первый член обучает prior подтягиваться к posterior, второй — posterior не уходить от prior
слишком далеко; порог 1 нат (free bits) отключает регуляризацию, когда она уже мала, не давая
латенту коллапсировать в prior. Порог применяется к каждой паре $(b, t)$ батча до усреднения.

**Полный лосс модели** на батче последовательностей $(B, T)$:

```math
\mathcal{L}_{\mathrm{wm}} = \mathbb{E}\Big[\sum_t -\log p(o_t \mid h_t, z_t) - \log p(r_t \mid h_t, z_t)
- \log p(c_t \mid h_t, z_t) + \mathcal{L}_{\mathrm{KL},t}\Big],
```

где $c_t = 1 - d_t$ — предсказание продолжения эпизода (нужно для бутстрапа в
воображении). Декодер изображений — гауссиана с единичной дисперсией, то есть
$-\log p(o \mid \cdot)$ есть сумма квадратов ошибок по пикселям с точностью до константы;
награда и ценности регрессируются дискретно (two-hot, лекция 5, §5.3) в symlog-пространстве,
$\mathrm{symlog}(x) = \mathrm{sign}(x)\log(1 + \lvert x \rvert)$, что выравнивает масштабы
задач. Векторные наблюдения кодируются и декодируются тоже в symlog-пространстве.

**Начало окна.** Окна буфера не пересекают границы эпизодов (`ReplayBuffer`), поэтому
$h_0, z_0$ и предыдущее действие в начале каждого окна обнуляются; это заменяет механизм
`is_first` DreamerV3, который обнуляет состояние внутри окна.

## 4.4. Обучение политики в воображении

От каждого апостериорного состояния батча $(h_t, z_t)$ (всего $B T$ стартов) запускается
прогон по prior на горизонт $H = 15$ с действиями актёра
$\hat a_\tau \sim \pi_\psi(\cdot \mid \hat s_\tau)$, $\hat s_\tau = (\hat h_\tau, \hat z_\tau)$.
Модель даёт $\hat r_\tau, \hat c_\tau$.

**λ-доходность** (TD(λ) с бутстрапом критиком $v_\xi$):

```math
R^\lambda_\tau = \hat r_{\tau+1} + \gamma\, \hat c_{\tau+1} \Big[(1-\lambda)\, v_\xi(\hat s_{\tau+1})
+ \lambda R^\lambda_{\tau+1}\Big], \qquad R^\lambda_{H} = v_\xi(\hat s_H),
```

$\lambda = 0.95$, $\gamma = 0.997$. Вычисляется обратной рекурсией по $\tau$ за $O(H)$ на
тензоре $(H, BT)$; при $\lambda = 0$ это одношаговый TD, при $\lambda = 1$ — Монте-Карло с
терминальным бутстрапом (тест `test_lambda_return`). Веса шагов
$w_\tau = \prod_{k \le \tau} \gamma \hat c_k$ обнуляют вклад после предсказанного конца
эпизода. В курсе бутстрап делается EMA-копией критика $v_{\bar\xi}$ (DreamerV3 использует
текущего критика, а EMA-копию — как регуляризатор; обе схемы встречаются).

**Критик**: дискретная регрессия $v_\xi(\hat s_\tau) \to \mathrm{sg}(R^\lambda_\tau)$ плюс
кросс-энтропия к распределению EMA-копии (регуляризатор DreamerV3, замедляющий дрейф).

**Актёр**: максимизация $R^\lambda$. Поскольку модель дифференцируема, для непрерывных
действий градиент берётся напрямую через прогон (репараметризация действий и
straight-through через категориальный латент) — это выбор DreamerV1/V2 и значение по
умолчанию для непрерывных действий в DreamerV3; для дискретных действий DreamerV3 применяет
REINFORCE. Лосс актёра:

```math
\mathcal{L}_\pi = -\mathbb{E}\Big[\sum_{\tau=0}^{H-1} w_\tau \Big(\frac{R^\lambda_\tau}{\max(1, S)}
+ \eta\, \mathcal{H}(\pi_\psi(\cdot \mid \hat s_\tau))\Big)\Big], \qquad \eta = 3 \cdot 10^{-4},
```

где $S$ — скользящая оценка разброса доходностей (разность 95-го и 5-го перцентилей).
Нормировка на $\max(1, S)$, а не на $S$, не усиливает шум при малых доходностях и делает
$\eta$ переносимым между задачами с разным масштабом наград.

**Утверждение 4.3.** В воображении горизонт $H$ ограничивает накопление ошибки модели: в
выводе утверждения 4.1 сумма геометрической прогрессии заменяется суммой $H$ членов, и
множитель $1/(1-\gamma)$ переходит в $\min(H, 1/(1-\gamma))$; хвост доходности за горизонтом
заменяет критик. Это обосновывает малые $H$ при больших $\gamma$.

## 4.5. Модели без декодера

Реконструкция наблюдения заставляет латент хранить всё, включая фон и шум. Альтернативы:

- **самосогласованность латента** (TD-MPC2, лекция 5):
  $\lVert d(z_t, a_t) - \mathrm{sg}(e(o_{t+1})) \rVert^2$; латент обязан быть предсказуемым и
  информативным для награды и $Q$, но не для пикселей;
- **предобученные визуальные энкодеры** (DINO-WM, Zhou et al., 2024): динамика учится в
  замороженном пространстве признаков (лекция 7).

Отсутствие декодера требует предосторожностей против коллапса (все $z$ одинаковы): в
TD-MPC2 — нормализация SimNorm и сигнал от $Q$/награды; в JEPA-подобных моделях —
регуляризация дисперсии или EMA-целевой энкодер.

## 4.6. Диагностика модели мира

Прежде чем учить политику, модель проверяют в открытом цикле (`Dreamer.open_loop_error`):
по $k$ первым наблюдениям вычисляют posterior, затем $K$ шагов идут по prior с реальными
действиями. Метрики: ошибка предсказания награды $\lvert \hat r - r \rvert$, ошибка
реконструкции, для пикселей — визуальное сравнение. Рост ошибки должен быть плавным; скачок
на шаге $k+1$ означает, что prior не согласован с posterior (слишком малый
$\beta_{\mathrm{dyn}}$ или KL ниже порога free bits при неинформативном латенте).
