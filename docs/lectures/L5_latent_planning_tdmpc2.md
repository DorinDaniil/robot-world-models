# Лекция 5. Планирование в латентном пространстве: MPPI и TD-MPC2

Цель: вывести сэмплирующий MPC (MPPI), описать модель и обучающую цель TD-MPC2 и показать,
как планирование и обученная ценность дополняют друг друга. Реализация:
`src/rwm/algos/tdmpc2.py`.

## 5.1. Управление с прогнозирующей моделью

Пусть известны (или обучены) динамика $z_{t+1} = d(z_t, a_t)$, награда $R(z, a)$ и
терминальная ценность $Q(z, a)$. Задача MPC на горизонте $H$:

```math
a_{t:t+H-1}^\star = \arg\max_{a_{t:t+H-1}} \; \sum_{k=0}^{H-1} \gamma^k R(z_{t+k}, a_{t+k})
+ \gamma^H Q\big(z_{t+H}, \pi(z_{t+H})\big),
```

исполняется первое действие, на следующем шаге задача решается заново (receding horizon).
Терминальный член заменяет бесконечный хвост доходности и позволяет держать $H$ малым, что
по утверждению 4.1 ограничивает влияние ошибки модели.

## 5.2. MPPI как вариационный вывод

Пусть $A = a_{t:t+H-1}$, $G(A)$ — доходность плана, $p(A)$ — базовое распределение
(гауссиана с параметрами $\mu, \sigma$). Рассмотрим задачу

```math
\max_q \; \mathbb{E}_{A \sim q}[G(A)] - \tau\, \mathrm{KL}(q \,\Vert\, p).
```

**Утверждение 5.1.** Решение имеет вид $q^\star(A) \propto p(A)\exp(G(A)/\tau)$.

*Доказательство.* Лагранжиан с ограничением нормировки $\int q = 1$:
$\int q\,(G - \tau \log q + \tau \log p)\,dA - \nu \big(\int q\,dA - 1\big)$. Вариация по $q$ даёт
$G - \tau(\log q + 1) + \tau \log p - \nu = 0$, откуда $\log q = \log p + G/\tau + \mathrm{const}$.
Целевая функция вогнута по $q$, поэтому стационарная точка — максимум. $\square$

Проектирование $q^\star$ обратно на гауссово семейство (минимизация
$\mathrm{KL}(q^\star \Vert \mathcal{N}(\mu', \sigma'^2))$ даёт моментные оценки) по выборке
$A_i \sim \mathcal{N}(\mu, \sigma^2)$:

```math
\mu' = \frac{\sum_i \omega_i A_i}{\sum_i \omega_i}, \qquad
\sigma'^2 = \frac{\sum_i \omega_i (A_i - \mu')^2}{\sum_i \omega_i}, \qquad
\omega_i = \exp\Big(\frac{G(A_i) - \max_j G(A_j)}{\tau}\Big).
```

Сдвиг на $\max_j G$ — численная стабилизация: веса не зависят от него. Несколько итераций
такого обновления — алгоритм MPPI (Williams et al., 2017); при $\tau \to 0$ с усечением до
лучших $k$ образцов получаем CEM. Тонкость: самовыборка $A_i \sim q$ вместо $p$ делает
оценку моментов смещённой; это «эмпирический» MPPI, и итерации играют роль
самосогласования.

**Алгоритм 5.1 (MPPI в латенте, как в TD-MPC2).**

```
вход: z_t; μ ← сдвиг μ с предыдущего шага (тёплый старт), σ ← σ_max
повторять J раз (J = 6):
    A_1..A_N ~ N(μ, σ²) с отсечением в [−1, 1]; A_{N+1..N+Nπ} ← прогон policy prior из z_t по d
    для каждого A_i: z ← z_t; G_i ← Σ_k γ^k R(z, a_k), z ← d(z, a_k); G_i += γ^H Q̂(z, π(z))
    оставить top-k по G_i (k = 64); ω_i ← exp((G_i − max G)/τ)
    μ ← Σ ω_i A_i / Σ ω_i;  σ ← sqrt(Σ ω_i (A_i − μ)² / Σ ω_i), σ ← clip(σ, σ_min, σ_max)
выход: a_t = μ_0 + σ_0 ε при обучении, μ_0 при оценке
```

$N = 512$, $N_\pi = 24$, $H = 3$, $\tau = 0.5$, $\sigma \in [0.05, 2]$. В авторском коде
температура входит как множитель $\exp(\kappa (G_i - \max G))$ с $\kappa = 0.5$, то есть
$\tau = 2$ в обозначениях выше; в курсе используется деление. Стоимость:
$J \cdot (N + N_\pi) \cdot H$ вызовов $d$ и $R$ — все батчируются, поэтому один шаг
планирования стоит несколько прямых проходов небольших MLP.

## 5.3. Модель TD-MPC2

Компоненты (Hansen, Su, Wang, 2024), все — MLP с LayerNorm и Mish:

| Символ | Назначение | Вход → выход |
|---|---|---|
| $h_\theta$ | энкодер | $o \to z \in \mathbb{R}^{L}$ |
| $d_\theta$ | латентная динамика | $(z, a) \to z'$ |
| $R_\theta$ | награда | $(z, a) \to$ распределение над бинами |
| $Q_\theta^{(1..5)}$ | ансамбль критиков | $(z, a) \to$ распределение над бинами |
| $p_\theta$ | policy prior | $z \to \mathcal{N}(\mu, \sigma^2)$, затем $\tanh$ |

**SimNorm.** Латент $z$ разбивается на $L/8$ групп по 8 компонент, к каждой применяется
softmax. Образ — произведение симплексов: норма латента ограничена, что предотвращает
коллапс и взрыв масштабов при обучении динамики без декодера.

**Дискретная регрессия (two-hot).** Награда и $Q$ предсказываются как категориальные
распределения на сетке $b_1 \lt \dots \lt b_m$ в symlog-пространстве. Скалярная цель $y$
кодируется two-hot: при $b_j \le \mathrm{symlog}(y) \lt b_{j+1}$

```math
p_j = \frac{b_{j+1} - \mathrm{symlog}(y)}{b_{j+1} - b_j}, \qquad p_{j+1} = 1 - p_j,
```

остальные нули; математическое ожидание распределения равно $\mathrm{symlog}(y)$
(упражнение 3). Лосс — кросс-энтропия; декодирование — $\mathrm{symexp}$ от ожидания по
softmax. По сравнению с MSE это устойчиво к масштабу наград и к выбросам: градиент
кросс-энтропии по логитам ограничен, в отличие от градиента квадратичной ошибки.

**Лосс модели** на батче подпоследовательностей длины $T$ ($T = H = 3$):

```math
\mathcal{L}(\theta) = \frac{1}{T}\sum_{t=0}^{T-1} \rho^t \Big(
c_1 \big\lVert d_\theta(z_t, a_t) - \mathrm{sg}\big(h_{\theta}(o_{t+1})\big)\big\rVert_2^2
+ c_2\, \mathrm{CE}\big(R_\theta(z_t, a_t), r_t\big)
+ c_3 \sum_{i=1}^{5} \mathrm{CE}\big(Q^{(i)}_\theta(z_t, a_t), y_t\big)\Big),
```

где $z_0 = h_\theta(o_0)$, $z_{t+1} = d_\theta(z_t, a_t)$ (латент прокатывается по модели, а
не перекодируется — так модель учится на собственных ошибках), $\rho = 0.5$ — дисконт по
времени внутри лосса, $c = (20, 0.1, 0.1)$, и

```math
y_t = r_t + \gamma\, (1 - d_t)\, \min_{i \in \mathcal{I}} Q^{(i)}_{\bar\theta}
\big(\mathrm{sg}(h_\theta(o_{t+1})), \tilde a_{t+1}\big), \qquad
\tilde a_{t+1} \sim p_\theta(\cdot \mid h_\theta(o_{t+1})),
```

$\mathcal{I}$ — два случайно выбранных индекса ансамбля, $\bar\theta$ — EMA-копия
($\tau_{\mathrm{ema}} = 0.01$). Цель вычисляется от закодированного, а не прокатанного
латента: ошибка динамики не должна попадать в TD-цель.

**Policy prior.** Максимизация энтропийно-регуляризованной ценности (как в SAC, лекция 1,
§1.7), но градиент идёт только через $p_\theta$, латент считается константой:

```math
\mathcal{L}_p(\theta) = \mathbb{E}\Big[\sum_t \rho^t \Big(\alpha \log p_\theta(\tilde a_t \mid z_t)
- \frac{\bar Q_\theta(z_t, \tilde a_t)}{\max(1, S)}\Big)\Big], \qquad \alpha = 10^{-4},
```

$\bar Q$ — среднее по ансамблю, $S$ — скользящая оценка размаха $Q$ (перцентили 5 и 95).
Нормировка делает $\alpha$ переносимым между задачами с разным масштабом наград.

**Роль prior.** На этапе планирования $p_\theta$ (а) даёт часть кандидатов ($N_\pi$ из
$N + N_\pi$), (б) задаёт действие в терминальном члене $Q(z_H, p_\theta(z_H))$. Планировщик
улучшает prior локально; prior даёт планировщику хорошую область поиска. Выбор `mpc: false`
превращает агент в model-based актёр-критик без планирования — обязательная абляция.

## 5.4. Обучение

**Алгоритм 5.2 (TD-MPC2, один процесс).**

```
собрать N0 шагов случайно; буфер эпизодов
повторять:
    a_t ← MPPI(h_θ(o_t))  (с шумом σ_0 при обучении)
    шаг среды, запись в буфер
    батч подпоследовательностей (o_{t..t+T}, a, r, d)
    шаг по L(θ) для энкодера, динамики, R, Q; шаг по L_p(θ) для prior
    θ̄ ← (1−τ_ema) θ̄ + τ_ema θ
```

UTD $= 1$, $\lvert B \rvert = 256$, $\eta = 3\cdot 10^{-4}$, градиент клипуется по норме 20.
В авторской реализации $\gamma$ зависит от длины эпизода $T_{\mathrm{ep}}$:
$\gamma = \mathrm{clip}\big((T_{\mathrm{ep}}/5 - 1)/(T_{\mathrm{ep}}/5),\, 0.95,\, 0.995\big)$,
что даёт $0.95$ для 100 шагов и $0.967$ для 150; в курсе $\gamma$ задаётся конфигом.

Для нескольких задач одновременно добавляется обучаемый эмбеддинг задачи, подаваемый всем
модулям; действия дополняются нулями до максимальной размерности (лекция 7, §7.1).

## 5.5. Сравнение с Dreamer

| | Dreamer | TD-MPC2 |
|---|---|---|
| Латент | стохастический, GRU | детерминированный MLP, SimNorm |
| Обучающий сигнал латента | реконструкция + KL | самосогласованность + награда + $Q$ |
| Действие | актёр в воображении, $H = 15$ | MPPI, $H = 3$, терминальная $Q$ |
| Память | есть (GRU): POMDP | нет; для пикселей — стек кадров |
| Стоимость шага в среде | один прямой проход | $J(N+N_\pi)H$ проходов (батчированы) |
| Устойчивость к ошибке модели | ограничена $H$ и критиком | ограничена $H$ и $Q$; план пересчитывается каждый шаг |

Общие элементы: symlog/two-hot регрессия, EMA-цели, нормировка доходностей на перцентили.
Разница в принципе: Dreamer амортизирует планирование в актёре, TD-MPC2 платит вычислениями
на каждом шаге за адаптивность к текущему состоянию.
