# Лекция 1. Марковские процессы принятия решений и обучение с подкреплением

Цель лекции — зафиксировать формальный аппарат, в терминах которого формулируются все
последующие методы, и вывести алгоритм актёр-критик с максимизацией энтропии (SAC), который
служит в курсе базовой линией.

## 1.1. Марковский процесс принятия решений

**Определение 1.1.** Марковский процесс принятия решений (MDP) — набор
$\mathcal{M} = (\mathcal{S}, \mathcal{A}, P, r, \gamma, \rho_0)$, где
$\mathcal{S}$ — множество состояний, $\mathcal{A}$ — множество действий,
$P(s' \mid s, a)$ — ядро переходов, $r: \mathcal{S} \times \mathcal{A} \to \mathbb{R}$ —
функция награды, $\gamma \in [0, 1)$ — коэффициент дисконтирования,
$\rho_0$ — распределение начального состояния.

В задачах управления роботом $\mathcal{S} \subset \mathbb{R}^n$ (обобщённые координаты и
скорости, положения объектов), $\mathcal{A} = [-1, 1]^m$. Награда ограничена:
$|r| \le R_{\max}$.

**Политика** $\pi(a \mid s)$ — условное распределение на действиях. Взаимодействие порождает
траекторию $\tau = (s_0, a_0, r_0, s_1, \dots)$ с плотностью
$p_\pi(\tau) = \rho_0(s_0) \prod_t \pi(a_t \mid s_t) P(s_{t+1} \mid s_t, a_t)$.

**Доходность** $G_t = \sum_{k \ge 0} \gamma^k r_{t+k}$. Ограниченность награды даёт
$|G_t| \le R_{\max}/(1-\gamma)$; величину $1/(1-\gamma)$ интерпретируют как эффективный горизонт.

**Определение 1.2.** Функции ценности:
$$V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s], \qquad
Q^\pi(s, a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a].$$

Цель: $\pi^* = \arg\max_\pi J(\pi)$, где $J(\pi) = \mathbb{E}_{s_0 \sim \rho_0}[V^\pi(s_0)]$.

## 1.2. Уравнения Беллмана

Из определения и марковости следует
$$Q^\pi(s, a) = r(s, a) + \gamma\, \mathbb{E}_{s' \sim P(\cdot \mid s, a)}\big[V^\pi(s')\big],
\qquad V^\pi(s) = \mathbb{E}_{a \sim \pi(\cdot \mid s)}[Q^\pi(s, a)].$$

Оптимальные функции $Q^* = \max_\pi Q^\pi$ удовлетворяют уравнению оптимальности
$$Q^*(s, a) = r(s, a) + \gamma\, \mathbb{E}_{s'}\big[\max_{a'} Q^*(s', a')\big].$$

**Утверждение 1.1.** Оператор Беллмана $(\mathcal{T}Q)(s,a) = r(s,a) + \gamma \mathbb{E}_{s'}
\max_{a'} Q(s',a')$ является сжатием в норме $\|\cdot\|_\infty$ с коэффициентом $\gamma$.

*Доказательство.* Для любых $Q_1, Q_2$:
$|(\mathcal{T}Q_1 - \mathcal{T}Q_2)(s,a)| \le \gamma\, \mathbb{E}_{s'} |\max_{a'} Q_1 - \max_{a'} Q_2|
\le \gamma \|Q_1 - Q_2\|_\infty$. $\square$

По теореме Банаха итерации $Q_{k+1} = \mathcal{T} Q_k$ сходятся к $Q^*$ из любого начального
приближения. Все методы временных разностей — стохастические аппроксимации этого оператора.

## 1.3. Частичная наблюдаемость

Робот с камерой не наблюдает $s_t$. **POMDP** добавляет пространство наблюдений
$\mathcal{O}$ и ядро $O(o \mid s)$. Достаточной статистикой истории
$h_t = (o_0, a_0, \dots, o_t)$ является апостериорное распределение (belief)
$b_t(s) = p(s_t \mid h_t)$; задача на beliefs — снова MDP, но на бесконечномерном
пространстве. На практике используют один из двух приёмов:

1. **Стек кадров**: $\tilde{o}_t = (o_{t-k+1}, \dots, o_t)$ — достаточно, когда состояние
   восстанавливается по конечной истории (например, скорости из двух кадров).
2. **Рекуррентное состояние**: $h_t = f_\theta(h_{t-1}, a_{t-1}, o_t)$ — обучаемая аппроксимация
   достаточной статистики; именно это делает RSSM в лекции 3.

Если наблюдение содержит $q, \dot q$ и положения объектов, задача марковская, и приёмы не нужны.
Поэтому отладка алгоритмов всегда начинается в режиме `obs_mode="state"`.

## 1.4. Эпизоды, завершение и усечение

Эпизодические задачи заканчиваются по одной из двух причин, которые необходимо различать:

- **Завершение** (terminated): достигнуто терминальное состояние, из которого будущих
  наград нет. Цель бутстрапа: $y = r$.
- **Усечение** (truncated): эпизод прерван внешним ограничением $t = T$, хотя процесс
  продолжился бы. Цель бутстрапа: $y = r + \gamma V(s')$.

Подмена усечения завершением вносит систематическое смещение в $Q$ порядка
$\gamma V(s_T)$ на каждом эпизоде; для задач с фиксированным горизонтом (`ReachEnv`) это
распространённая ошибка. Контракт Gymnasium возвращает оба флага раздельно.

## 1.5. Обучение временными разностями

Пусть $Q_\phi$ — параметрическая аппроксимация, $\mathcal{D}$ — буфер переходов
$(s, a, r, s', d)$, где $d$ — индикатор завершения. Семиградиентная TD-регрессия:
$$\mathcal{L}(\phi) = \mathbb{E}_{\mathcal{D}}\Big[\big(Q_\phi(s,a) - y\big)^2\Big], \qquad
y = r + \gamma (1 - d)\, Q_{\bar\phi}(s', a'),$$
где $\bar\phi$ — параметры целевой сети, обновляемые экспоненциальным сглаживанием
$\bar\phi \leftarrow (1-\rho)\bar\phi + \rho\phi$, $\rho \sim 5\cdot 10^{-3}$. Цель $y$
считается без градиента.

Комбинация функциональной аппроксимации, бутстрапа и обучения вне политики (off-policy) не
имеет гарантий сходимости в общем случае («смертельная триада», Sutton & Barto, §11.3);
целевые сети, ансамбли $Q$ и ограничение нормы градиента — эмпирические стабилизаторы.

## 1.6. Градиент политики и актёр-критик

**Теорема 1.1 (градиент политики).** Для $\pi_\theta$, дифференцируемой по $\theta$,
$$\nabla_\theta J(\pi_\theta) = \mathbb{E}_{s \sim d^\pi,\, a \sim \pi_\theta}
\big[\nabla_\theta \log \pi_\theta(a \mid s)\, Q^\pi(s, a)\big],$$
где $d^\pi$ — дисконтированное распределение посещения состояний.

Вычитание из $Q^\pi$ любой функции $b(s)$ не меняет математического ожидания, но меняет
дисперсию; выбор $b = V^\pi$ даёт функцию преимущества $A^\pi = Q^\pi - V^\pi$. Схема
актёр-критик: критик $Q_\phi$ оценивает $Q^\pi$, актёр $\pi_\theta$ делает шаг по оценке
градиента.

Для непрерывных действий с детерминированной или репараметризуемой политикой
$a = f_\theta(s, \varepsilon)$ градиент берут напрямую через критика:
$\nabla_\theta J \approx \mathbb{E}\big[\nabla_a Q_\phi(s, a)\big|_{a = f_\theta(s,\varepsilon)}
\nabla_\theta f_\theta(s, \varepsilon)\big]$. Это снижает дисперсию по сравнению с оценкой
по формуле теоремы 1.1 ценой смещения от ошибки критика.

## 1.7. Soft Actor-Critic

**Постановка.** Максимизируется энтропийно-регуляризованная цель
$$J_\alpha(\pi) = \mathbb{E}_\pi\Big[\sum_t \gamma^t \big(r(s_t, a_t) + \alpha\,
\mathcal{H}(\pi(\cdot \mid s_t))\big)\Big],$$
$\alpha > 0$ — температура. Регуляризация поощряет исследование и делает оптимальную
политику стохастической; при $\alpha \to 0$ получаем исходную задачу.

**Мягкие уравнения Беллмана.**
$$Q^\pi(s,a) = r(s,a) + \gamma\,\mathbb{E}_{s'}[V^\pi(s')], \qquad
V^\pi(s) = \mathbb{E}_{a \sim \pi}\big[Q^\pi(s,a) - \alpha \log \pi(a \mid s)\big].$$

**Улучшение политики.** Для фиксированного $Q$ оптимальная политика в классе всех
распределений: $\pi(a \mid s) \propto \exp(Q(s,a)/\alpha)$. В параметрическом классе
минимизируют KL до этого распределения:
$$\mathcal{L}_\pi(\theta) = \mathbb{E}_{s \sim \mathcal{D},\, a \sim \pi_\theta}
\big[\alpha \log \pi_\theta(a \mid s) - Q_\phi(s, a)\big].$$
Можно показать (Haarnoja et al., 2018, лемма 2), что такой шаг не уменьшает $Q^\pi$.

**Параметризация действий.** $\pi_\theta$: гауссиана $\mathcal{N}(\mu_\theta(s),
\sigma^2_\theta(s))$ с последующим $a = \tanh(u)$, чтобы $a \in (-1, 1)^m$. Плотность
корректируется якобианом:
$\log \pi(a \mid s) = \log \mathcal{N}(u; \mu, \sigma^2) - \sum_i \log(1 - \tanh^2 u_i)$.
Градиент по $\theta$ берётся репараметризацией $u = \mu + \sigma \odot \varepsilon$,
$\varepsilon \sim \mathcal{N}(0, I)$.

**Критик.** Два независимых $Q_{\phi_1}, Q_{\phi_2}$ и цель с минимумом (clipped double Q) для
компенсации переоценки, возникающей из $\max$ по зашумлённым оценкам:
$$y = r + \gamma(1-d)\Big[\min_{i} Q_{\bar\phi_i}(s', a') - \alpha \log \pi_\theta(a' \mid s')\Big],
\quad a' \sim \pi_\theta(\cdot \mid s').$$

**Температура.** Вместо фиксированного $\alpha$ решается двойственная задача с ограничением
на энтропию $\mathcal{H}(\pi(\cdot \mid s)) \ge \bar{\mathcal{H}}$, $\bar{\mathcal{H}} = -m$:
$$\mathcal{L}(\alpha) = \mathbb{E}_{a \sim \pi_\theta}\big[-\alpha \log \pi_\theta(a \mid s)
- \alpha \bar{\mathcal{H}}\big].$$

**Алгоритм 1.1 (SAC).**
```
инициализировать θ, φ1, φ2; φ̄i ← φi; буфер D
собрать N0 переходов случайной политикой
повторять:
    a ~ π_θ(·|s); (s', r, d) ← env.step(a); D ← D ∪ {(s,a,r,s',d)}
    для k = 1..UTD:
        B ~ D
        φi ← φi − η ∇ 1/|B| Σ (Q_φi(s,a) − y)^2,   i = 1,2
        θ  ← θ − η ∇ 1/|B| Σ [α log π_θ(ã|s) − min_i Q_φi(s,ã)],  ã = f_θ(s,ε)
        α  ← α − η ∇ L(α)
        φ̄i ← (1−ρ) φ̄i + ρ φi
```

Гиперпараметры, воспроизводящие результаты оригинальной работы: $\eta = 3\cdot10^{-4}$,
$|B| = 256$, $\rho = 0.005$, $\gamma = 0.99$, сети $256{\times}256$, UTD $= 1$.

## 1.8. Протокол эксперимента

- Обучение и оценка используют разные экземпляры среды и непересекающиеся сиды.
- Оценочная политика детерминирована ($a = \tanh \mu_\theta(s)$); число оценочных эпизодов
  $\ge 10$.
- Отчётные величины: средняя доходность и доля успехов, усреднённые по $\ge 3$ сидам, с
  указанием стандартной ошибки. Один сид не является результатом: разброс между сидами в
  задачах непрерывного управления часто сопоставим с эффектом метода (Henderson et al., 2018).

## Упражнения

1. Доказать, что добавление константы к награде не меняет оптимальной политики в
   бесконечно-горизонтном дисконтированном MDP, но может изменить её в эпизодическом с
   переменной длиной эпизода.
2. Показать, что оператор $\mathcal{T}^\pi$ (оценка фиксированной политики) — сжатие, и оценить
   $\|Q_k - Q^\pi\|_\infty$ после $k$ итераций.
3. Вывести поправку якобиана для $\tanh$ в §1.7 и объяснить, почему в реализации её
   записывают как $2(\log 2 - u - \mathrm{softplus}(-2u))$.
4. Для `ReachEnv` оценить ошибку в $Q$, возникающую при трактовке усечения как завершения,
   предполагая $V(s_T) \approx -d_T/(1-\gamma)$, где $d_T$ — конечное расстояние.
5. (Практика, лаб. 2) Реализовать SAC по алгоритму 1.1 и воспроизвести кривую обучения на
   `ReachEnv` для 3 сидов.
