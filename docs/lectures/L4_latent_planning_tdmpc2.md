# Лекция 4. Планирование в латентном пространстве: MPPI и TD-MPC2

Цель: вывести сэмплирующий MPC (MPPI), описать модель и обучающую цель TD-MPC2 и показать,
как планирование и обученная ценность дополняют друг друга.

## 4.1. Управление с прогнозирующей моделью

Пусть известны (или обучены) динамика $z_{t+1} = d(z_t, a_t)$, награда $R(z, a)$ и
терминальная ценность $Q(z, a)$. Задача MPC на горизонте $H$:
$$a_{t:t+H-1}^* = \arg\max_{a_{t:t+H-1}} \; \sum_{k=0}^{H-1} \gamma^k R(z_{t+k}, a_{t+k})
+ \gamma^H Q\big(z_{t+H}, \pi(z_{t+H})\big),$$
исполняется первое действие, на следующем шаге задача решается заново (receding horizon).
Терминальный член заменяет бесконечный хвост доходности и позволяет держать $H$ малым, что
по утверждению 3.1 ограничивает влияние ошибки модели.

## 4.2. MPPI как вариационный вывод

Пусть $A = a_{t:t+H-1}$, $G(A)$ — доходность плана, $p(A)$ — базовое распределение
(гауссиана с параметрами $\mu, \sigma$). Рассмотрим задачу
$$\max_q \; \mathbb{E}_{A \sim q}[G(A)] - \tau\, \mathrm{KL}(q \| p).$$
**Утверждение 4.1.** Решение имеет вид $q^*(A) \propto p(A)\exp(G(A)/\tau)$.

*Доказательство.* Лагранжиан по $q$ с ограничением нормировки; стационарная точка
$G(A) - \tau(\log q - \log p) - \tau - \nu = 0$. $\square$

Проектирование $q^*$ обратно на гауссово семейство (минимизация $\mathrm{KL}(q^*\|
\mathcal N(\mu', \sigma'))$) даёт моментные оценки:
$$\mu' = \frac{\sum_i \omega_i A_i}{\sum_i \omega_i}, \qquad
\sigma'^2 = \frac{\sum_i \omega_i (A_i - \mu')^2}{\sum_i \omega_i}, \qquad
\omega_i = \exp\big((G(A_i) - \max_j G(A_j))/\tau\big),$$
где $A_i \sim \mathcal N(\mu, \sigma^2)$. Сдвиг на $\max_j G$ — численная стабилизация.
Несколько итераций такого обновления — алгоритм MPPI (Williams et al., 2017); при $\tau \to 0$
и усечении до лучших $k$ образцов получаем CEM.

**Алгоритм 4.1 (MPPI в латенте, как в TD-MPC2).**
```
вход: z_t; μ ← сдвиг μ с предыдущего шага (warm start), σ ← σ_0
повторять J раз (J = 6):
    A_1..A_N ~ N(μ, σ²), A_{N+1..N+Nπ} ← прогон policy prior π из z_t по модели d
    для каждого A_i: z ← z_t; G_i ← Σ_k γ^k R(z, a_k); z ← d(z, a_k); G_i += γ^H Q(z, π(z))
    оставить top-k по G_i (k = 64); ω_i ← exp((G_i − max G)/τ)
    μ ← Σ ω_i A_i / Σ ω_i;  σ ← sqrt(Σ ω_i (A_i − μ)² / Σ ω_i), σ ← clip(σ, σ_min, σ_max)
выход: a_t ~ N(μ_0, σ_0²)  (при оценке — μ_0)
```
Стоимость: $J \cdot (N + N_\pi) \cdot H$ вызовов $d$ и $R$ — все батчируются, поэтому один
шаг планирования стоит несколько прямых проходов небольших MLP.

## 4.3. Модель TD-MPC2

Компоненты (Hansen, Su, Wang, 2024), все — MLP с LayerNorm и Mish:

| Символ | Назначение | Вход → выход |
|---|---|---|
| $h_\theta$ | энкодер | $o \to z \in \mathbb{R}^{L}$ |
| $d_\theta$ | латентная динамика | $(z, a) \to z'$ |
| $R_\theta$ | награда | $(z, a) \to$ распределение над бинами |
| $Q_\theta^{(1..5)}$ | ансамбль критиков | $(z, a) \to$ распределение над бинами |
| $p_\theta$ | policy prior | $z \to \mathcal N(\mu, \sigma^2)$, затем $\tanh$ |

**SimNorm.** Латент $z$ разбивается на $L/8$ групп по 8 компонент, к каждой применяется softmax.
Это ограничивает норму латента (симплексы), предотвращая коллапс и взрыв масштабов при
обучении динамики без декодера.

**Дискретная регрессия.** Награда и $Q$ предсказываются как категориальные распределения на
сетке $\{b_1, \dots, b_m\}$ в symlog-пространстве; скалярная цель $y$ кодируется
two-hot: масса распределяется между двумя соседними бинами пропорционально близости.
Лосс — кросс-энтропия. По сравнению с MSE это устойчиво к масштабу наград и к выбросам.

**Лосс модели** на батче последовательностей длины $T$ (в статье $T = 3$):
$$\mathcal{L}(\theta) = \mathbb{E}\Big[\sum_{t=0}^{T-1} \lambda^t \Big(
c_1 \big\|d_\theta(z_t, a_t) - \mathrm{sg}\big(h_{\theta}(o_{t+1})\big)\big\|_2^2
+ c_2\, \mathrm{CE}\big(R_\theta(z_t, a_t), r_t\big)
+ c_3\, \mathrm{CE}\big(Q_\theta(z_t, a_t), y_t\big)\Big)\Big],$$
где $z_0 = h_\theta(o_0)$, $z_{t+1} = d_\theta(z_t, a_t)$ (латент прокатывается по модели, а не
перекодируется), $\lambda = 0.5$ — дисконт по времени внутри лосса, $c = (20, 0.1, 0.1)$, и
$$y_t = r_t + \gamma\, \mathrm{sg}\Big(\min_{i \in \mathcal I} Q^{(i)}_{\bar\theta}
\big(z_{t+1}, \tilde a_{t+1}\big)\Big), \qquad \tilde a_{t+1} \sim p_\theta(\cdot \mid z_{t+1}),$$
$\mathcal I$ — два случайно выбранных индекса ансамбля, $\bar\theta$ — EMA-копия.

**Policy prior.** Максимизация энтропийно-регуляризованной ценности (как в SAC, лекция 1.7),
но градиент идёт только через $p_\theta$, латент считается константой:
$$\mathcal{L}_p(\theta) = \mathbb{E}\Big[\sum_t \lambda^t \big(\alpha \log p_\theta(\tilde a_t \mid z_t)
- \bar Q_\theta(z_t, \tilde a_t)\big)\Big], \qquad \bar Q = \text{среднее по ансамблю},$$
с нормировкой $Q$ на скользящую оценку размаха (как в DreamerV3) и малым $\alpha$.

**Роль prior.** На этапе планирования $p_\theta$ (а) даёт часть кандидатов ($N_\pi = 24$ из
$N + N_\pi = 536$), (б) задаёт действие в терминальном члене $Q(z_H, p_\theta(z_H))$.
Планировщик улучшает prior локально; prior даёт планировщику хорошую область поиска.
Выбор `mpc=False` превращает агент в обычный model-based актёр-критик — это полезная
абляция.

## 4.4. Обучение

**Алгоритм 4.2 (TD-MPC2, один процесс).**
```
собрать N0 шагов случайно; буфер эпизодов
повторять:
    a_t ← MPPI(h_θ(o_t))  (с шумом σ при обучении)
    шаг среды, запись в буфер
    батч подпоследовательностей (o_{t..t+T}, a, r)
    шаг по L(θ) для энкодера, динамики, R, Q; шаг по L_p(θ) для prior
    θ̄ ← (1−ρ) θ̄ + ρ θ
```
UTD $= 1$, $|B| = 256$, $\eta = 3\cdot 10^{-4}$, $\gamma$ зависит от длины эпизода
(для 100 шагов $\approx 0.95$–$0.97$), градиент клипуется по норме 20.

Для нескольких задач одновременно добавляется обучаемый эмбеддинг задачи, подаваемый всем
модулям; действия дополняются нулями до максимальной размерности. В курсе это не используется.

## 4.5. Сравнение с Dreamer

| | Dreamer | TD-MPC2 |
|---|---|---|
| Латент | стохастический, GRU | детерминированный MLP |
| Обучающий сигнал латента | реконструкция + KL | самосогласованность + награда + $Q$ |
| Действие | актёр в воображении, $H = 15$ | MPPI, $H = 3$, терминальная $Q$ |
| Память | есть (GRU) — POMDP | нет; для пикселей стек кадров |
| Стоимость шага в среде | один прямой проход | $J(N+N_\pi)H$ проходов (батчированы) |
| Устойчивость к ошибке модели | ограничена $H$ и критиком | ограничена $H$ и $Q$; план пересчитывается каждый шаг |

Общие элементы: symlog/two-hot регрессия, EMA-цели, нормировка доходностей, высокий UTD.
Разница в принципе: Dreamer амортизирует планирование в актёре, TD-MPC2 платит вычислениями на
каждом шаге за адаптивность к текущему состоянию.
