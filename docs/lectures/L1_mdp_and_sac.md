# Лекция 1. Марковские процессы принятия решений и Soft Actor-Critic

Цель лекции — зафиксировать формальный аппарат, в терминах которого формулируются все
последующие методы, и вывести алгоритм актёр-критик с максимизацией энтропии (SAC),
который служит в курсе базовой линией. Реализация: `src/rwm/algos/sac.py`.

## 1.1. Марковский процесс принятия решений

**Определение 1.1.** Марковский процесс принятия решений (MDP) — набор
$\mathcal{M} = (\mathcal{S}, \mathcal{A}, P, r, \gamma, \rho_0)$: множество состояний,
множество действий, ядро переходов $P(s' \mid s, a)$, функция награды
$r: \mathcal{S} \times \mathcal{A} \to \mathbb{R}$, коэффициент дисконтирования
$\gamma \in [0, 1)$ и распределение начального состояния $\rho_0$.

В задачах управления роботом $\mathcal{S} \subset \mathbb{R}^n$ (обобщённые координаты,
скорости, положения объектов), $\mathcal{A} = [-1, 1]^m$. Награда ограничена:
$\lvert r \rvert \le R_{\max}$.

**Политика** $\pi(a \mid s)$ — условное распределение на действиях. Взаимодействие порождает
траекторию $\tau = (s_0, a_0, r_0, s_1, \dots)$ с плотностью

```math
p_\pi(\tau) = \rho_0(s_0) \prod_{t \ge 0} \pi(a_t \mid s_t)\, P(s_{t+1} \mid s_t, a_t).
```

**Доходность** $G_t = \sum_{k \ge 0} \gamma^k r_{t+k}$. Из ограниченности награды
$\lvert G_t \rvert \le R_{\max}/(1-\gamma)$; величину $1/(1-\gamma)$ называют эффективным
горизонтом.

**Определение 1.2.** Функции ценности политики:

```math
V^\pi(s) = \mathbb{E}_\pi\big[G_t \mid s_t = s\big], \qquad
Q^\pi(s, a) = \mathbb{E}_\pi\big[G_t \mid s_t = s, a_t = a\big].
```

Цель: $\pi^\star = \arg\max_\pi J(\pi)$, $J(\pi) = \mathbb{E}_{s_0 \sim \rho_0}[V^\pi(s_0)]$.

## 1.2. Уравнения Беллмана

Из определения и марковости:

```math
Q^\pi(s, a) = r(s, a) + \gamma\, \mathbb{E}_{s' \sim P(\cdot \mid s, a)}\big[V^\pi(s')\big],
\qquad V^\pi(s) = \mathbb{E}_{a \sim \pi(\cdot \mid s)}\big[Q^\pi(s, a)\big].
```

Оптимальная функция $Q^\star = \max_\pi Q^\pi$ удовлетворяет уравнению оптимальности

```math
Q^\star(s, a) = r(s, a) + \gamma\, \mathbb{E}_{s'}\Big[\max_{a'} Q^\star(s', a')\Big].
```

**Утверждение 1.1.** Оператор Беллмана
$(\mathcal{T}Q)(s,a) = r(s,a) + \gamma\, \mathbb{E}_{s'} \max_{a'} Q(s',a')$
является сжатием в норме $\lVert \cdot \rVert_\infty$ с коэффициентом $\gamma$.

*Доказательство.* Для любых $Q_1, Q_2$ и любых $(s,a)$:

```math
\big|(\mathcal{T}Q_1 - \mathcal{T}Q_2)(s,a)\big|
\le \gamma\, \mathbb{E}_{s'}\Big|\max_{a'} Q_1(s',a') - \max_{a'} Q_2(s',a')\Big|
\le \gamma\, \mathbb{E}_{s'} \max_{a'} \big|Q_1(s',a') - Q_2(s',a')\big|
\le \gamma \lVert Q_1 - Q_2 \rVert_\infty .
```

Второе неравенство — свойство $\lvert \max f - \max g \rvert \le \max \lvert f - g \rvert$. $\square$

По теореме Банаха итерации $Q_{k+1} = \mathcal{T} Q_k$ сходятся к $Q^\star$ из любого
начального приближения, причём $\lVert Q_k - Q^\star \rVert_\infty \le \gamma^k \lVert Q_0 - Q^\star \rVert_\infty$.
Все методы временных разностей — стохастические аппроксимации этого оператора; гарантия
сжатия теряется при функциональной аппроксимации (§1.5).

## 1.3. Частичная наблюдаемость

Робот с камерой не наблюдает $s_t$. POMDP добавляет пространство наблюдений
$\mathcal{O}$ и ядро $O(o \mid s)$. Достаточной статистикой истории
$h_t = (o_0, a_0, \dots, o_t)$ является апостериорное распределение (belief)
$b_t(s) = p(s_t \mid h_t)$; задача на beliefs — снова MDP, но на бесконечномерном
пространстве. На практике используют один из двух приёмов:

1. **Стек кадров** $\tilde o_t = (o_{t-k+1}, \dots, o_t)$ — достаточно, когда состояние
   восстанавливается по конечной истории (скорости из двух кадров).
2. **Рекуррентное состояние** $h_t = f_\theta(h_{t-1}, a_{t-1}, o_t)$ — обучаемая
   аппроксимация достаточной статистики; именно это делает RSSM (лекция 4).

Если наблюдение содержит $q, \dot q$ и положения объектов, задача марковская, и приёмы не
нужны. Поэтому отладка алгоритмов всегда начинается в режиме `obs_mode="state"`.

## 1.4. Завершение и усечение эпизода

Эпизод заканчивается по одной из двух причин, которые необходимо различать:

- **Завершение** (terminated): достигнуто терминальное состояние, будущих наград нет.
  Цель бутстрапа $y = r$.
- **Усечение** (truncated): эпизод прерван внешним ограничением $t = T$, хотя процесс
  продолжился бы. Цель бутстрапа $y = r + \gamma V(s')$.

Подмена усечения завершением вносит в $Q$ систематическое смещение порядка
$\gamma V(s_T)$ на каждом эпизоде. В задачах курса (`Reach`, `Pick`) эпизоды только
усекаются, поэтому бутстрап никогда не обрывается. Контракт Gymnasium возвращает оба флага
раздельно; буфер `rwm.data.ReplayBuffer` хранит только `terminated` и всегда хранит
следующее наблюдение, в том числе для последнего шага усечённого эпизода.

## 1.5. Обучение временными разностями

Пусть $Q_\phi$ — параметрическая аппроксимация, $\mathcal{D}$ — буфер переходов
$(s, a, r, s', d)$, $d$ — индикатор завершения. Семиградиентная TD-регрессия:

```math
\mathcal{L}(\phi) = \mathbb{E}_{\mathcal{D}}\Big[\big(Q_\phi(s,a) - y\big)^2\Big], \qquad
y = r + \gamma (1 - d)\, Q_{\bar\phi}(s', a'),
```

где $\bar\phi$ — параметры целевой сети, обновляемые экспоненциальным сглаживанием
$\bar\phi \leftarrow (1-\rho)\bar\phi + \rho\phi$, $\rho = 5 \cdot 10^{-3}$. Цель $y$
считается без градиента («семиградиент»): дифференцирование $y$ по $\phi$ дало бы метод
остаточных градиентов, который сходится к другой неподвижной точке и на практике медленнее.

Комбинация функциональной аппроксимации, бутстрапа и обучения вне политики (off-policy) не
имеет гарантий сходимости в общем случае («смертельная триада», Sutton & Barto, §11.3);
целевые сети, ансамбли $Q$ и ограничение нормы градиента — эмпирические стабилизаторы.

## 1.6. Градиент политики и актёр-критик

**Теорема 1.1 (градиент политики).** Для $\pi_\theta$, дифференцируемой по $\theta$,

```math
\nabla_\theta J(\pi_\theta) = \mathbb{E}_{s \sim d^\pi,\, a \sim \pi_\theta(\cdot \mid s)}
\big[\nabla_\theta \log \pi_\theta(a \mid s)\, Q^\pi(s, a)\big],
\qquad d^\pi(s) = \sum_{t \ge 0} \gamma^t \Pr(s_t = s \mid \pi),
```

$d^\pi$ — ненормированное дисконтированное распределение посещения состояний.

Вычитание из $Q^\pi$ любой функции $b(s)$ не меняет математического ожидания
($\mathbb{E}_{a \sim \pi}[\nabla_\theta \log \pi_\theta(a \mid s)] = \nabla_\theta 1 = 0$),
но меняет дисперсию; выбор $b = V^\pi$ даёт функцию преимущества $A^\pi = Q^\pi - V^\pi$.
Схема актёр-критик: критик $Q_\phi$ оценивает $Q^\pi$, актёр $\pi_\theta$ делает шаг по
оценке градиента.

Для непрерывных действий с репараметризуемой политикой $a = f_\theta(s, \varepsilon)$,
$\varepsilon \sim p(\varepsilon)$, градиент берут напрямую через критика:

```math
\nabla_\theta J \approx \mathbb{E}_{s, \varepsilon}\Big[
\nabla_a Q_\phi(s, a)\big|_{a = f_\theta(s, \varepsilon)}\, \nabla_\theta f_\theta(s, \varepsilon)\Big].
```

Это снижает дисперсию по сравнению с оценкой теоремы 1.1 ценой смещения от ошибки
критика: оценка уже не является несмещённой оценкой истинного градиента $J$.

## 1.7. Soft Actor-Critic

**Постановка.** Максимизируется энтропийно-регуляризованная цель

```math
J_\alpha(\pi) = \mathbb{E}_\pi\Big[\sum_{t \ge 0} \gamma^t \big(r(s_t, a_t)
+ \alpha\, \mathcal{H}(\pi(\cdot \mid s_t))\big)\Big],
```

$\alpha \gt 0$ — температура. Регуляризация поощряет исследование и делает оптимальную
политику стохастической; при $\alpha \to 0$ получаем исходную задачу.

**Мягкие уравнения Беллмана.**

```math
Q^\pi(s,a) = r(s,a) + \gamma\,\mathbb{E}_{s'}\big[V^\pi(s')\big], \qquad
V^\pi(s) = \mathbb{E}_{a \sim \pi}\big[Q^\pi(s,a) - \alpha \log \pi(a \mid s)\big].
```

**Улучшение политики.** При фиксированном $Q$ оптимальная политика в классе всех
распределений — $\pi(a \mid s) \propto \exp(Q(s,a)/\alpha)$ (упражнение 2). В
параметрическом классе минимизируют KL до этого распределения; с точностью до не
зависящей от $\theta$ нормировки

```math
\mathcal{L}_\pi(\theta) = \mathbb{E}_{s \sim \mathcal{D},\, a \sim \pi_\theta(\cdot \mid s)}
\big[\alpha \log \pi_\theta(a \mid s) - Q_\phi(s, a)\big].
```

Haarnoja et al. (2018, лемма 2) показывают, что такой шаг не уменьшает $Q^\pi$ в табличном
случае; с аппроксимацией это эвристика.

**Параметризация действий.** $u \sim \mathcal{N}(\mu_\theta(s), \sigma^2_\theta(s))$,
$a = \tanh(u)$, чтобы $a \in (-1, 1)^m$. Плотность корректируется якобианом замены переменных:

```math
\log \pi(a \mid s) = \log \mathcal{N}(u; \mu, \sigma^2) - \sum_{i=1}^m \log\big(1 - \tanh^2 u_i\big).
```

Градиент по $\theta$ — репараметризацией $u = \mu + \sigma \odot \varepsilon$,
$\varepsilon \sim \mathcal{N}(0, I)$. В реализации $\log \sigma$ ограничивают отрезком
$[-5, 2]$: при $\sigma \to 0$ градиент log-плотности расходится.

**Критик.** Два независимых $Q_{\phi_1}, Q_{\phi_2}$ и цель с минимумом (clipped double Q):

```math
y = r + \gamma(1-d)\Big[\min_{i=1,2} Q_{\bar\phi_i}(s', a') - \alpha \log \pi_\theta(a' \mid s')\Big],
\qquad a' \sim \pi_\theta(\cdot \mid s').
```

Минимум компенсирует переоценку: если $\hat Q = Q + \xi$ с шумом $\xi$ нулевого среднего,
то $\mathbb{E}[\max_a \hat Q] \ge \max_a Q$ (неравенство Йенсена для выпуклого $\max$), и
бутстрап по собственным оценкам накапливает смещение вверх.

**Температура.** Вместо фиксированного $\alpha$ решается двойственная задача с
ограничением $\mathcal{H}(\pi(\cdot \mid s)) \ge \bar{\mathcal{H}}$, $\bar{\mathcal{H}} = -m$:

```math
\mathcal{L}(\alpha) = \mathbb{E}_{a \sim \pi_\theta}\big[-\alpha\, (\log \pi_\theta(a \mid s)
+ \bar{\mathcal{H}})\big].
```

Градиентный шаг по $\alpha$ увеличивает температуру, когда энтропия ниже целевой, и уменьшает
иначе; параметризация $\alpha = e^{\beta}$ сохраняет положительность.

**Алгоритм 1.1 (SAC).**

```
инициализировать θ, φ1, φ2; φ̄i ← φi; буфер D
собрать N0 переходов случайной политикой
повторять:
    a ~ π_θ(·|s); (s', r, d) ← env.step(a); D ← D ∪ {(s,a,r,s',d)}
    для k = 1..UTD:
        B ~ D
        φi ← φi − η ∇ (1/|B|) Σ (Q_φi(s,a) − y)²,                i = 1,2
        θ  ← θ − η ∇ (1/|B|) Σ [α log π_θ(ã|s) − min_i Q_φi(s,ã)],  ã = f_θ(s,ε)
        α  ← α − η ∇ L(α)
        φ̄i ← (1−ρ) φ̄i + ρ φi
```

Гиперпараметры, воспроизводящие результаты оригинальной работы: $\eta = 3\cdot10^{-4}$,
$\lvert B \rvert = 256$, $\rho = 0.005$, $\gamma = 0.99$, сети $256 \times 256$, UTD $= 1$.
В `sac.py` все три шага выполняются на одном батче; градиент актёра не попадает в критика,
потому что шаг критика уже сделан и `loss_pi.backward()` не вызывает `opt_critic.step()`.

## 1.8. Протокол эксперимента

- Обучение и оценка используют разные экземпляры среды и непересекающиеся сиды.
- Оценочная политика детерминирована ($a = \tanh \mu_\theta(s)$); число оценочных эпизодов
  $\ge 10$.
- Отчётные величины: средняя доходность и доля успехов, усреднённые по $\ge 3$ сидам, с
  указанием стандартной ошибки. Один сид не является результатом: разброс между сидами в
  непрерывном управлении часто сопоставим с эффектом метода (Henderson et al., 2018).

## Упражнения

1. Доказать, что добавление константы к награде не меняет оптимальной политики в
   бесконечно-горизонтном дисконтированном MDP, но может изменить её в эпизодическом с
   переменной длиной эпизода.
2. Показать, что $\arg\max_\pi \mathbb{E}_{a \sim \pi}[Q(s,a) - \alpha \log \pi(a \mid s)]$
   по всем распределениям на $\mathcal{A}$ есть $\pi \propto \exp(Q/\alpha)$ (метод множителей
   Лагранжа с ограничением нормировки), и что максимум равен
   $\alpha \log \int \exp(Q(s,a)/\alpha)\, da$.
3. Вывести поправку якобиана для $\tanh$ в §1.7 и показать тождество
   $\log(1 - \tanh^2 u) = 2\big(\log 2 - u - \mathrm{softplus}(-2u)\big)$. Почему вторая
   форма численно устойчивее при $\lvert u \rvert \gg 1$?
4. Для `Reach` оценить ошибку в $Q$, возникающую при трактовке усечения как завершения,
   предполагая $V(s_T) \approx -d_T/(1-\gamma)$, где $d_T$ — конечное расстояние до цели.
5. Показать, что оператор $\mathcal{T}^\pi$ (оценка фиксированной политики) — сжатие, и
   оценить $\lVert Q_k - Q^\pi \rVert_\infty$ после $k$ итераций.
